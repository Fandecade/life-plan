# 人生规划 · Life Planner 功能介绍

一个以**长期能力成长**为核心的个人自我管理与发展系统：把「方向 → 能力 → 项目/任务 → 时间 → 学习 → 习惯 → 复盘」串成可执行、可验证、可调整的闭环。

产品原则只有三条：

1. **系统负责提供反馈，不负责给人打分**：不做考勤式红黑榜，用「节奏偏缓」代替「完成率低」。
2. **能力必须有成果作为证据**：完成多少任务不等于掌握能力，阶段成果与成果证据才是验收标准。
3. **复盘必须产生调整，并验证调整是否有效**：先看客观数据，再把结论变成真实动作，下一期回看效果。

## 一、快速开始

### 运行环境
- Flutter 3.50+ / Dart 3.14+
- macOS（桌面）、Web、iOS / Android

### 启动

```bash
export FLUTTER_STORAGE_BASE_URL=https://storage.flutter-io.cn
export PUB_HOSTED_URL=https://pub.flutter-io.cn

flutter pub get
flutter run -d macos          # 桌面
flutter build web --release   # Web
```

首次启动会写入示例数据：一个愿景、两项能力、若干任务与一个已排期时间块。

### 界面骨架
- 左侧导航（窄屏为底部导航）：人生规划 → 项目 → 时间盒 → 输出式学习 → 福格习惯 → 及时复盘 → 设置
- `⌘K / Ctrl+K` 呼出居中的任务池面板；「安排记录」仅在时间盒显示
- 点击任务卡片打开右侧详情抽屉；抽屉底部挂载已启用模块的扩展槽位

## 二、六个模块的功能与用法

### 2.1 人生规划（图谱）

**它回答**：我要成为谁？需要建哪些能力？

**功能**
- 三级树状图谱：愿景 → 能力 → 任务 → 子任务（最多 3 级）
- 自动布局、缩放平移、贝塞尔连线、路径高亮、节点拖拽微调（位置持久化）
- **横/纵布局切换**：默认按设备自适应——手机（移动端最短边 < 600）从上到下，电脑/平板从左到右；切到纵向时愿景居顶居中、能力横向同排、任务逐级向下，连线同步改为自上而下（入口在视图工具组，手机端展开「视图工具」可见，手动切换后保留选择）
- 四类节点语义色（愿景 / 能力 / 任务 / 子任务）
- 任务圆圈：未完成点击即完成；**已完成再次点击会先确认「取消完成」**，可通过「保持完成」留在原地
- 折叠能力/任务，折叠后其子节点从画布移除
- 任务卡片也有「⋯」菜单（与愿景/能力一致）：编辑、添加子任务、删除任务（子任务一并软删除；最多 3 级）
- XMind 式键盘流：`空格` 打开详情、`Enter` 建同级、`Tab` 建子级
- **愿景管理**：新建默认追加到末尾；切换栏可横向滑动查看多个愿景
  - 桌面右键：只保留「删除这个愿景」（连带软删除其能力与任务）
  - 长按任意愿景进入编辑模式：胶囊轻微抖动、可拖动排序、右侧出现叉号删除；点「完成」退出
  - 手机端同样使用长按编辑，避免小区域弹菜单
- **能力阶段成果（Milestone）**：能力菜单 →「阶段成果」，可添加「能力达到什么水平、能独立完成什么」、填证据链接、勾选达成；能力卡片显示 `任务进度 · M 达成/总数`
- **能力证据**：阶段成果弹窗中展示从学习成果沉淀来的 Artifact（见 2.4）

**怎么用**
1. 新建愿景，写下 3–5 年方向
2. 在愿景下添加 2–4 项能力，并为每项能力写 1–3 条阶段成果（可验收）
3. 在能力下拆任务；任务完成只推进会进度，能力是否达标看阶段成果与证据

### 2.2 项目（综合实践）

**它回答**：通过什么综合实践形成并验证能力？

**功能**
- 项目独立于任务树，可关联**多项能力**
- 项目阶段是检查点（不是待办）：可添加、勾选推进、删除
- 验收标准：写明「怎样算完成」
- 产物链接：GitHub / 文档 / 演示地址
- 状态：进行中 / 暂停 / 已完成 / 归档，可按状态筛选
- 项目卡片显示：阶段 `x/y`、关联能力、任务数、产物标记
- 任务可挂到项目：任务详情 →「所属项目」

**怎么用**
1. 侧栏「项目」→ 新建项目，写目标与验收标准
2. 关联相关能力，添加阶段（如 准备 → 实现 → 验证 → 成果）
3. 在任务详情里把执行任务挂到项目
4. 推进阶段时勾选；完成后产物链接留档，作为能力证据

### 2.3 时间盒

**它回答**：这些事什么时候做？实际做了多少？

**四级视图**
- **日**：24 小时时间轴，15 分钟吸附；重叠块自动分列；当前时间线；顶部「今日微习惯」打卡条
- **周**：7 天 × 时间轴；左右拖动跨天、上下拖动改时间；固定安排块按规则生成
- **月**：每日负荷热力、复习节点、任务 DDL 徽章、月复盘状态；点击日期先看「当天简报」再进日视图；底部微习惯节律点
- **年**：12 个月卡片、活跃度与复盘轨迹、年度方向；点击月份下钻

**提醒**
- 默认在任务开始时刻提醒（到点通知）；可在「设置 → 提醒设置」改为提前 0–1440 分钟，预设 0/5/10/15/30 并支持自定义
- 同一分钟的多个时间盒块合并为一条提醒
- **应用内提醒与系统通知可分别关闭**：应用内为顶部横幅；系统通知在 Android / macOS 关闭应用后仍会送达
- 只定日期的任务当天 09:00 提醒一次（时间可改）；已有时间块的任务不重复提醒
- 微习惯每天 20:30 汇总提醒未完成数量（时间可改），当天全部完成则跳过
- 横幅与系统通知均支持「完成 / 稍后 10 分钟」；应用回到前台会补发 30 分钟内错过的提醒
- **系统通知**提前排未来 7 天；点击通知可跳到对应位置
- Web 不支持后台通知，自动降级为应用内横幅

**日视图交互（重要）**
- **滚轮 / 普通拖动 = 滚动时间轴**
- **长按约 0.5 秒后拖动 = 圈选时间格**，松手弹出「安排任务」
- 单击空白 = 直接安排
- 时间块改时间：**手机端长按约 0.5 秒后上下拖动整体移动**（抖动 + 触觉反馈，吸附 15 分钟，时长不变）；桌面端直接拖拽；右下角手柄始终用于调整时长
- 时间块样式：使用更实的语义色底（不再过度透明），标题、标签与时间行居中显示
- **日期确定、时段待定**：排期沿用「日历选日期 → 表盘选时间」，日期可任意切换；日历底部可直接「只安排到这一天」，不生成时间块；已有计划日期时还可「清除日期」（任务池、任务详情与复盘安排同样支持）
- 日视图顶部三枚胶囊切换：**今日待办（默认）/ 今日微习惯 / 时间安排**，一次只显示一个视图
- 今日待办：未定时间（每项「排期」打开日历，可只定日期）与已定时间两组；已完成保留划线；**已完成再次点击圆圈会先弹确认（取消完成），时间块同样需要确认**
- 今日微习惯：今日锚点完整习惯卡片（点阵、连续天数、点卡片打卡；更多菜单可调配方/行动线）
- 时间安排：24 小时时间轴（滚轮/拖动滚动，长按拖动圈选）

**一个任务多次推进**
- 改期：更新当前时间块（并同步任务）
- 任务详情「再排一次」：追加一个新时间块，旧块保留
- 卡片会显示「共 N 次排期」

**固定安排**
- 两类：纯固定事项（课程/例会）与绑定任务实例
- 懒生成到具体日期；支持编辑、仅本周跳过、恢复默认、删除、整周复制

**怎么用**
1. 从任务池把任务拖到时间轴排期
2. 每天按块执行并勾完成（普通任务完成；学习任务只推进到进行中，交给学习模块判定）
3. 固定的课表用「固定安排」，临时变化用「仅本周跳过」

### 2.4 输出式学习

**它回答**：我是否真的学会了？

**五类方法（各 4 步）**

| 类型 | 四步 | 复习间隔 |
|---|---|---|
| 陈述性（概念/费曼） | 设问 → 定向输入与建网 → 独立输出 → 校验与排期 | 1/3/7/15/30 天 |
| 程序性（刻意练习） | 锁定短板 → 闭卷实战与反馈 → 错因归因输出 → 薄弱点重练 | 1/3/7 天 |
| 项目式 | 最小骨架 → 定向补盲 → 可运行原型 → 边界与迁移总结 | 1/7/15/30 天 |
| 语言 | 盲听精听 → 影子跟述 → 脱稿复述造句 → 语料检索 | 1/3/7/15 天 |
| 自定义 | 目标与输入 → 独立输出 → 自检与补盲 → 总结与排期 | 1/3/7/15/30 天 |

**双档**
- 完整输出：走完四步
- 5 分钟微输出：只保留核心输出（陈述性 / 自定义支持）

**功能**
- **学习计时**：进入学习后手动「开始计时」，实时显示本次时长；可暂停/继续，离开或完成时自动结算；累计到该次学习会话（暂停不计时）
- 列表式逐点输入（回车落点），按步骤断点保存草稿
- 完成前自检门禁三选
- 卡点速记 + 外部成果链接
- 主动回忆：顺畅（间隔×2，上限 60 天）/ 模糊（保持）/ 遗忘（回 1 天）；连续两次顺畅可提前通关
- 复习块自动落入时间盒 20:00，点开直接进入回忆
- 两层状态：待巩固（权重 0.7）→ 彻底完成（1.0）
- 输出成果库：按步骤折叠查看、删除记录、重新学习
- **记为能力成果**：在成果库打开某次成果 →「记为能力成果」，选择类型（概念解释/推导/习题/代码/项目/表达）、关联能力、填链接，即成为能力证据

**怎么用**
1. 在任务详情把任务设为「输出式学习」并选方法
2. 按四步完成一次独立输出，过自检门禁
3. 在成果库把成果记为能力成果；按复习队列做主动回忆
4. 复习结果会自动调整下一次间隔，连续顺畅可提前通关

### 2.5 福格习惯

**它回答**：怎么让好行为自然发生，而不是靠意志力？

**页面**
- 胶囊：`今日锚点 · N` / `全部习惯` / `行动线诊断` / `配方调整记录`
- 今日锚点按晨间 / 日间间隙 / 晚间收尾 / 随时触发分组

**习惯与打卡**
- 卡片：锚点提示 → 微行为、14 天低饱和点阵、连续天数（温和计算）
- 一键打卡；撤销（取消今天的打卡）需二次确认，避免误触回退连续天数；「记超额」只记增量，不抬高次日门槛
- 无红叉、无断签惩罚；右键/长按或「⋯」可调整配方、诊断、停用、删除

**六步配方**
锚点 → 微行为（15 秒~2 分钟）→ 即时庆祝 → 锚点时段 → 5 维阻力（时间/金钱/体力/脑力/日程）→ 行为集群与焦点地图（可关联任务/能力）

**焦点地图**
- 中间十字轴：左难做 / 右易做，下低影响 / 上高影响，右上为黄金区
- 节点宽度随名称自适应；同档位自动散开；拖动为连续坐标
- 点击确认是否放入本次配方

**行动线诊断与推演**
- 顶部公式：`B = M（动机）× A（能力）× P（提示）`
- 多习惯散点 + 行动线（线上易触发 / 线下易卡住）
- 四个可调参数：能力值 / 动机值 / 门槛 / 弯曲度
- COM-B 诊断（能力 / 机会 / 动机）提示主卡点方向
- 应用后削减阻力、补强庆祝/锚点，生成 v+1 配方；配方记录可看历史落点对比

**怎么用**
1. 先建 1 个习惯，只填锚点 + 20 秒动作
2. 连续打卡一周，不追求数量
3. 卡住时打开行动线诊断，按提示缩小微行为或换锚点
4. 稳定后用「动作升级」把动作放大一档

### 2.6 及时复盘

**它回答**：怎样做得更好？之前的调整有效吗？

**四级**
- 日（3–5 分钟）：今日亮点 + 明日最关键 1–3 件事
- 周（15–20 分钟）：Keep / 瓶颈 + 元认知自问 / 结构性调整 / If–Then
- 月（30 分钟）：能力推进 / 停滞与偏离 / 目标减法
- 年：年度代表作 / 愿景对齐 / 下一年布局

**数据看板（自动读取所有模块）**
- 时间投入：计划 / 时间盒完成时长 + 完成率 +「较上期」（执行口径）
- 学习投入：学习计时累计的真实时长（附带计时的会话次数）
- 任务与学习：完成数、新增巩固、独立输出
- 微习惯节律：完成率、节奏偏缓数量
- 能力精力分布条：点击跳图谱并定位能力
- **指标分层**（周/月/年）：执行 / 学习 / 能力 / 习惯 / 对齐，五类分开呈现，不合成总分
- **认知负荷结构**：高/中/低分钟分布；高负荷 > 60% 提示保留 10–15% 缓冲
- **学习策略有效性**：知识类型 × 输出档位的复习顺畅率（样本 ≥ 2）
- **配方版本执行率**：v1 → v2 对比；内嵌习惯行动线；年复盘年度成果精选

**待校准事项（5 类，每项都可执行、可撤销、可「暂不调整」）**

| 事项 | 主要动作 | 结果 |
|---|---|---|
| 未完成时间块 | 安排日期 | 自由选日期/时间/时长，同步时间盒 |
| 未完成时间块 | ⋯ 拆解任务（去图谱） / 回任务池 / 取消 | 跳转定位 / 解除排期 / 删块并延后任务 |
| 未完成时间块 | ⋯ 判断原因并调整… | 目标过大/能力不足/时间不足/行为阻力/目标失效/估时不准 → 对应动作 |
| 逾期复习 | 安排时间 / ⋯ 分散复习负载… | 自由安排并生成时间盒块 / 可配天数、每日上限与时间 |
| 节奏偏缓习惯 | 调配方 | 打开行动线诊断与推演 |
| 停滞任务 | 归档 | 标记为已延后 |
| 学习卡点 | 生成补盲任务 / 确认补盲 | 主动记录直接生成；关键词命中需确认，可忽略 |
| 今日待办未完成 | 安排时间 / ⋯ 顺延到明天 / 回任务池 | 生成时间盒块 / 改计划日 / 清空日期（不计时间投入） |

**其他**
- 上期调整回看：显示上期「调整方案 + 预期效果」，补填「实际效果」写回上期
- 历史：列出所有复盘，点击跳回对应周期
- 沉淀：周/月/年把有效模式一键沉淀为微习惯或学习模板
- 标记完成可随时点；再次点击「已完成」会确认后撤销
- 处理过的项可「撤销」，回滚动作与已处理标记（会话内）

**怎么用（日复盘）**
看数据 → 处理未完成块/逾期复习 → 写亮点与明日 1–3 件事 → 标记完成。
**怎么用（周复盘）**
看能力分布与负荷 → 判因处理异常 → 写 Keep/瓶颈/下周调整/If–Then → 沉淀有效模式 → 标记完成。

### 2.7 设置

- 外观：跟随系统 / 浅色 / 深色
- **提醒设置**（二级页）：应用内提醒 / 系统通知开关、时间盒提前量（含自定义）、只定日期任务与微习惯汇总时间
- 模块管理：关闭模块只隐藏入口与槽位，数据完整保留
- 本地数据：
  - 重新载入示例数据、清空全部数据
  - **导出备份**：弹出系统保存对话框，把全量 JSON 存为 `life-plan-backup-日期.json`（Web 端直接下载）
  - **从文件恢复**：选择本地 `.json` 备份文件，二次确认后覆盖业务数据（设置保留），建议重启刷新

## 三、模块之间如何联动

### 3.1 总览

| 源 | 去向 | 联动内容 |
|---|---|---|
| 人生规划 | 项目 | 能力是项目的关联对象；阶段成果是能力验收标准 |
| 人生规划 | 时间盒 | 拖拽任务排期；完成同步任务状态 |
| 人生规划 | 学习 / 习惯 | 任务详情槽位挂载学习与微习惯 |
| 项目 | 任务 / 能力 | 任务挂到项目；项目关联多能力 |
| 时间盒 | 复盘 | 计划/实际时长、完成率、能力分布、负荷结构、未完成块 |
| 输出式学习 | 时间盒 | 完成后生成复习块（20:00），点块直接回忆 |
| 输出式学习 | 能力 | 成果记为 Artifact，成为能力证据 |
| 输出式学习 | 复盘 | 独立输出、按时回忆率、盲区、补盲任务、学习策略 |
| 福格习惯 | 时间盒 | 日视图微习惯条、月历节律点 |
| 福格习惯 | 复盘 | 节律完成率、节奏偏缓、配方执行率、内嵌行动线 |
| 复盘 | 全部 | 安排日期/时间、拆解去图谱、分散负载、补盲、归档、调配方、定位能力/任务 |
| 设置 | 全部 | 模块开关、主题、备份与恢复 |

### 3.2 三条典型链路

**① 从方向到执行**
愿景 → 能力（+阶段成果）→ 项目（关联能力）→ 任务 → 时间盒排期 → 完成 → 复盘能力推进。

**② 从学习到证据**
任务设为输出式学习 → 四步输出 → 过自检 → 生成复习块 → 成果记为 Artifact → 能力阶段成果有证据 → 复盘「能力」指标可见。

**③ 从复盘到调整**
复盘数据发现未完成块 → 判断原因（时间不足）→ 安排日期 → 下期回看「调整方案 + 预期 + 实际效果」→ 形成反馈闭环。

## 四、数据与模型概况

### 4.1 存储
- Hive（纯 Dart 本地库），所有实体以 JSON 落在各自 box
- **15 个业务 box + 1 个设置 box**

| box | 实体 | 说明 |
|---|---|---|
| `visions` | Vision | 愿景（含切换排序 `sortOrder`） |
| `capabilities` | Capability | 能力（含阶段成果 `milestonesJson`） |
| `action_items` | ActionItem | 任务/子任务（含学习模式、If–Then、认知负荷、所属项目、计划日期） |
| `time_blocks` | TimeBlock | 时间块（可多块/任务、可绑复习、可绑固定安排） |
| `learning_sessions` | LearningSession | 学习会话、草稿与计时秒数（`elapsedSeconds`） |
| `learning_reviews` | LearningReview | 间隔复习 |
| `weekly_routines` | WeeklyRoutine | 固定安排模板 |
| `routine_exceptions` | RoutineException | 单周跳过 |
| `fogg_habits` | FoggHabit | 微习惯配方 |
| `habit_logs` | HabitLog | 每日打卡 |
| `behavior_candidates` | BehaviorCandidate | 焦点地图候选 |
| `habit_recipe_versions` | HabitRecipeVersion | 配方版本快照 |
| `review_logs` | ReviewLog | 复盘文本、已处理、统计快照、调整效果 |
| `artifacts` | Artifact | 能力成果证据 |
| `projects` | Project | 项目（能力/阶段/验收/产物） |
| `settings` | — | 主题与模块开关 |

### 4.2 公共字段
所有实体继承 `SyncEntity`：`id` / `createdAt` / `updatedAt` / `deletedAt`（软删除）/ `syncStatus`（同步预留）。

### 4.3 关系

```
Vision 1─n Capability
Capability 1─n ActionItem           Capability n─n Project（capabilityIds）
ActionItem 1─n ActionItem（父子，最多 3 级）
Project 1─n ActionItem（projectId）
ActionItem 1─n TimeBlock
TimeBlock n─1 LearningReview
TimeBlock n─1 WeeklyRoutine
ActionItem 1─n LearningSession 1─n LearningReview
ActionItem 1─n Artifact（能力证据可同时关联 capability）
FoggHabit n─1 ActionItem/Capability；1─n HabitLog；1─n HabitRecipeVersion
ReviewLog（periodType + periodKey）独立汇总
```

### 4.4 安全与迁移
- 删除一律软删除；界面隐藏、数据保留
- 复盘「已处理」持久化在 `handledItemsJson`
- 备份包含全部业务 box（不含设置）；导入后建议重启
- 二期可基于 `syncStatus` 接入服务端同步（尚未实现）

## 五、一天 / 一周 / 一月怎么用

- **早晨**：看时间盒今日块 → 顶部微习惯条打卡
- **白天**：按块执行；临时想法丢进任务池（⌘K）
- **晚上**：日复盘 3 分钟：看数据 → 处理未完成块/复习 → 写明日 1–3 件事
- **周末**：周复盘 15 分钟：能力分布 → 判因处理 → Keep/瓶颈 → If–Then → 沉淀有效模式
- **月末**：月复盘 30 分钟：能力推进 → 目标减法 → 调整方案与预期 → 看负荷/策略/配方对比
- **年末**：年复盘：愿景对齐 → 年度成果精选 → 下一年布局

## 七、总结

Life Planner 把「我想成为谁」拆成可验证的能力与证据，把「该做什么」放进真实时间，把「是否学会」交给独立输出与间隔复习，把「如何持续」交给行为设计，最后用复盘把数据变成调整、并验证调整是否有效。

一句话：**方向靠图谱，落地靠时间盒与项目，掌握靠输出与证据，持续靠习惯，纠偏靠复盘。**
